# Nutritionist RAG — Project Scaffold

Personalized nutrition/sleep guidance grounded in real guideline documents,
built with LangChain + Chroma. See `nutritionist-rag-4-week-plan.md` for the
full build plan and design rationale.

## Setup

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # then add your OPENAI_API_KEY
```

## Add your guideline documents

Download the PDFs from the data source list (Dietary Guidelines for
Americans 2025–2030, WHO fact sheets, CDC/Sleep Foundation sleep guidance)
and place them in `data/guidelines/`. See `nutritionist-rag-4-week-plan.md`
for the specific links.

## Build the vector store

```bash
python src/ingestion.py
```

This chunks and embeds every PDF in `data/guidelines/` into a persistent
Chroma store at `data/chroma_db/`. Re-run this only when source documents
change.

## Try the nutrient lookup table

`data/nutrients/common_foods.csv` ships with ~20 common foods (egg, rice,
chicken breast, etc.) so the pipeline is testable immediately. Swap this for
a USDA FNDDS or SR Legacy export once the pipeline works end-to-end — see
the "Nutrient database" section of the plan doc for the migration notes.

```bash
python src/nutrient_lookup.py   # quick manual test, no LLM needed
python src/metrics_tool.py      # quick manual test of BMI/TDEE math
```

## Run the full agent

```bash
python src/agent.py
```

This runs a sample question through the full pipeline: metrics calculation
+ nutrient lookup + guideline retrieval, merged into one grounded, cited
response.

## Project structure

```
nutritionist-rag/
├── data/
│   ├── guidelines/       # put your guideline PDFs here (not included)
│   ├── nutrients/        # common_foods.csv — starter nutrient table
│   └── chroma_db/        # generated by ingestion.py, git-ignore this
├── src/
│   ├── metrics_tool.py     # BMI / TDEE / sleep deficit — deterministic math
│   ├── nutrient_lookup.py  # exact food -> nutrient table lookup
│   ├── ingestion.py        # PDF -> chunks -> embeddings -> Chroma
│   ├── retriever.py        # hybrid BM25 + vector retriever
│   └── agent.py            # wires all three tools + LLM + memory
├── requirements.txt
└── .env.example
```
